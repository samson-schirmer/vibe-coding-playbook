# Vibe Coding Playbook

Reusable Codex skills, design references, and library decisions for building better AI-assisted software and UI.

## Contents

- `skills/`: installable Codex skills.
- `design-md/`: starter `DESIGN.md` templates for common product types.
- `library-decisions/`: practical decision records for libraries and sources.
- `workflow-decisions/`: process and agent workflow decisions.
- `references/`: curated source links and usage notes.
- `licenses/`: license and copying notes for third-party sources.

## Operating Model

Keep canonical files in this repo. Install active skills into `~/.codex/skills/` when you want Codex to use them automatically.

For project-specific work, copy only the relevant `DESIGN.md` guidance into that project. Do not copy paid or proprietary reference screenshots unless the source license permits it.

## Recommended Stack

- Superpowers plugin: use for planning, TDD, debugging, code review, and branch-completion workflows.
- This playbook's local skills: use for design research, UI composition, animation, and dashboard/data visualization taste.
- Project `AGENTS.md` and `DESIGN.md`: use for repo-specific behavior and product-specific visual rules.
