# Bklit for Charts

## Use Bklit UI When

- the project uses React, Tailwind, shadcn/ui, and Motion
- you need polished dashboard or analytics components
- generated registry or copy-paste component workflow fits the repo

## Use Local Charts When

- the chart is simple
- the project already has chart primitives
- adding another source would create styling drift
