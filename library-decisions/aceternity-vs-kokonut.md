# Aceternity vs Kokonut

## Default

Use existing project components first. Add third-party components only when they save meaningful work or improve quality.

## Aceternity UI

Best for expressive animated sections, marketing pages, hero treatments, and visual effects in React/Next/Tailwind/Motion projects.

Check the Aceternity license before copying or redistributing components.

## Kokonut UI

Best for open-source Tailwind, shadcn/ui, and Motion components that can be adapted into app UI.

The Kokonut UI repository states it is MIT licensed.

## Rule

Do not combine both visual languages on one page unless the imported components are heavily normalized to the same design system.
