# Motion vs Anime.js

## Default

Use Motion for React and Next.js UI animation.

## Use Motion When

- animation is tied to React state
- you need layout transitions
- you need gestures, drag, hover, tap, or scroll interactions
- accessibility and reduced-motion handling matter

## Use Anime.js When

- the project is not React-centric
- SVG or DOM timeline animation is the core task
- you need framework-agnostic animation primitives

## Avoid Both When

CSS transition or keyframes solve the problem cleanly.
