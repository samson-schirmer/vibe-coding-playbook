# Source Decisions

Use this order when composing UI:

1. Local project components for consistency.
2. shadcn/ui for accessible primitives.
3. Bklit UI for charts and dashboards.
4. Kokonut UI for MIT-licensed Tailwind/shadcn/Motion components.
5. Aceternity UI for animated marketing and expressive site sections.
6. Custom code for narrow or project-specific needs.

Avoid mixing multiple expressive component libraries in one surface. Pick one visual direction and normalize tokens.
