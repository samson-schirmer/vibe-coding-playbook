# Element Patterns

Choose a pattern that matches the claim.

| Relationship | Pattern | Construction |
| --- | --- | --- |
| One source creates options | Fan-out | One source ellipse, diverging arrows, free labels |
| Many inputs become one | Convergence | Several sources, arrows merging into one output |
| A sequence happens over time | Timeline | Line spine, small dot markers, free labels |
| An input changes state | Assembly line | Input, action rectangle, output, directional arrows |
| Options diverge by condition | Decision | Diamond, labeled exits, clear arrow routing |
| A system has nested responsibility | Tree | Structural lines with free labels, not node cards |
| Two approaches differ | Side-by-side | Parallel structures with one explicit contrast |

Keep most labels free-floating. Use a dark rectangle for evidence artifacts such as a payload or source snippet, with chalk text and a purple key line only when that artifact is the diagram's signal.
