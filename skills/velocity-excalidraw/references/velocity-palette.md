# Velocity Palette

Use these colors literally. Purple has one semantic job in each diagram.

| Role | Hex | Use |
| --- | --- | --- |
| Ground | `#0E0E11` | Canvas and dark evidence panels |
| Chalk | `#F2F0EA` | Primary type and key strokes |
| Chalk dim | `#9C9A90` | Labels and supporting copy |
| Slate line | `#4A4A4E` | Dividers and secondary connectors |
| Purple signal | `#6138F5` | One primary state, decision, or outcome |
| Purple deep | `#4A28C8` | Signal outline where contrast needs more weight |

Use `#0E0E11` for the Excalidraw `viewBackgroundColor`. Pair purple fill with chalk text. Use chalk or slate for all non-signal objects.
