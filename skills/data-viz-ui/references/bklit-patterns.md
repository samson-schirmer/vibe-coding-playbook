# Bklit Patterns

Bklit UI is most relevant when a project already uses React, Tailwind, shadcn/ui, and Motion.

Before adding it:
- inspect existing chart dependencies
- confirm the chart type is materially better than a local implementation
- check whether generated registry JSON or copied component code is appropriate for the repo
- preserve license notes when copying MIT-licensed components

Dashboard checklist:
- loading, empty, error, and stale-data states
- timezone and date-range clarity
- responsive table/chart behavior
- accessible colors and labels
- stable units and series naming
