# Source Map

Use these sources for different jobs:

- Refero Styles: AI-readable `DESIGN.md` examples for visual systems, colors, typography, spacing, and component rules.
- Refero: product UI research, flow reasoning, and polished real-world web/app references.
- Mobbin: real app screens and full flows, especially mobile and common product patterns.
- Recent: broad visual trend scan; do not treat it as implementation guidance.
- UX laws: interaction and flow decision rules that complement visual references; read `../../../references/ux-laws.md`.
- Project `DESIGN.md`: source of truth when present.

Do not save proprietary screenshots directly into project repos. Save links and concise observations.
