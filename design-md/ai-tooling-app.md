# AI Tooling App DESIGN.md Starter

## Product Feel

Capable, transparent, and work-focused. The interface should show what the AI is doing without becoming theatrical.

## Layout

- clear input area
- visible execution/status area
- artifact or result pane
- concise history
- settings separated from the main flow

## Visual Rules

- avoid generic purple-gradient AI styling unless brand requires it
- show state with text and structured progress, not only animation
- keep generated artifacts inspectable
- separate prompts, logs, outputs, and actions visually

## Interaction

- allow pause/cancel where work may run long
- make destructive actions explicit
- preserve source context and decisions in the output
