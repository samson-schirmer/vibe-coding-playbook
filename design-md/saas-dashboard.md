# SaaS Dashboard DESIGN.md Starter

## Product Feel

Quiet, operational, dense, and fast to scan. Avoid marketing-page hero composition inside the app.

## Layout

- persistent navigation
- compact page header with primary action
- filter row near affected data
- KPI summary only when it changes decisions
- charts and tables sized for comparison

## Visual Rules

- neutral background with restrained accent colors
- 8px or smaller card radius unless project tokens differ
- stable chart colors across the product
- no decorative gradient blobs
- visible loading, empty, error, and stale-data states

## Interaction

- fast hover and focus feedback
- keyboard-accessible filters and menus
- responsive tables with deliberate column priority
