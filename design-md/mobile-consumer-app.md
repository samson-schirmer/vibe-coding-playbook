# Mobile Consumer App DESIGN.md Starter

## Product Feel

Clear, tactile, and focused on repeat daily use. Keep primary actions reachable and screens easy to recover from.

## Layout

- one primary task per screen
- bottom navigation only for stable top-level areas
- thumb-friendly primary actions
- progressive disclosure for complex settings

## Visual Rules

- high contrast text
- clear touch targets
- restrained animation for state changes
- avoid tiny dense controls unless the user expects pro tooling

## Interaction

- preserve input state
- confirm destructive actions
- design offline, empty, and permission-denied states
